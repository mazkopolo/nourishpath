# NourishPath GitHub Pages

This folder contains the three public pages needed for App Store Connect:

- `index.htm` — Marketing URL
- `support.htm` — Support URL
- `privacy.htm` — Privacy Policy URL

## Before publishing

Replace every `REPLACE-WITH-YOUR-EMAIL` occurrence with the real monitored support email address.

GitHub Pages normally expects `index.html`. GitHub serves `index.htm` when linked directly, but renaming `index.htm` to `index.html` will make the repository root open automatically. The other `.htm` pages can remain unchanged.

## Suggested App Store Connect URLs

After publishing at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`:

- Marketing URL: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
- Support URL: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/support.htm`
- Privacy Policy URL: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/privacy.htm`
